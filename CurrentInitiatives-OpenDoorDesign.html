Projects in Motion

SR Document Remediation Tool

Focus: PDF accessibility, tagged document workflows, forms, graphics, and screen reader review.

SR Document Remediation Tool is a screen reader-focused PDF accessibility review and remediation concept. It is designed to support workflows involving tagged documents, graphics, forms, accessibility roles, and review decisions.

The project demonstrates accessibility engineering by addressing a common barrier: PDF remediation workflows are often visual, complex, and difficult to use efficiently with assistive technology.

Key accessibility concepts include keyboard usability, clear section order, role selection, form detection, graphics review, alternate text support, and screen reader-friendly status feedback.

Media Workflow Assistant

Focus: source-aware media inspection, goal-oriented workflows, screen reader-first operation, accessible outputs, and provider-independent media preparation.

The Media Workflow Assistant is a new application that begins with the user's goal rather than a complicated media tool. A user selects a local media file, the application inspects it, identifies available actions, and offers clear workflows without requiring the user to understand command-line utilities, codecs, download tools, or media platforms.

The first complete end-to-end workflow is Prepare for AI. The Media Inspector analyzes the selected file, the Recommendation Engine identifies the action, the Workflow Runner executes it, and the Browser Provider creates a real Markdown file for download.

Future development will add URL input for video and other media sources. The assistant will identify the source and content type, inspect what can be accessed, and offer the same goal-oriented actions for links as it does for local files. Additional workflows may support captions, transcripts, audio description, accessible summaries, segment review, conversion, and other media-access goals.

Status: Active development with the first end-to-end workflow complete

The Beepball Practice Caller has developed into a usable audio training application rather than remaining a concept. It supports accessible controls and repeatable practice for players using randomized calls and directional audio.

Flash Trainer and Accessibility Practice Tools

Focus: accessible learning systems, challenge workflows, interactive accessibility practice, and assistive technology-compatible study environments.

Flash Trainer concepts explore accessibility education through structured learning systems, challenge modes, review workflows, and interactive accessibility practice.

The goal is to create learning environments that support screen reader users, keyboard navigation, clear feedback, and usability-focused interaction patterns while helping learners build practical accessibility understanding.

The project also explores how accessibility education can become more interactive through challenge systems, review modes, exported learning records, and screen reader-compatible quiz workflows.

Accessible Interaction and Media Examples

Focus: accessibility evaluation, component usability analysis, keyboard interaction models, screen reader behavior, and accessible multimedia workflows.

Accessible Carousel Engineering Example

Open Door Design includes accessibility-focused carousel examples designed to demonstrate keyboard accessibility, screen reader interaction, focus management, accessible navigation, and instructional usability concepts.

The carousel work explores how commonly inaccessible interface patterns can be redesigned to support users who rely on screen readers and keyboard interaction.

The examples also demonstrate the importance of reducing repetitive announcements, maintaining logical reading order, and improving clarity for assistive technology users.

Open the accessible carousel example

Accessible Media Player Design Reference

Open Door Design also evaluates accessible multimedia interaction patterns using reference examples created by other organizations, including an accessible media player developed by eComback.

The media player example demonstrates strong accessibility concepts involving keyboard operation, media controls, screen reader interaction, and simplified multimedia workflows.

The example is included as part of ongoing accessibility evaluation and usability analysis work involving accessible media experiences and assistive technology support.
