Open Door Accessibility Academy

Learning Accessibility by Building Accessibility

The Open Door Accessibility Academy is the learning center of Open Door Design. It is being created to help people understand accessibility through plain language, practical examples, screen reader-first workflows, and hands-on practice.

The Academy is in its founding season. The courses, learning programs, examples, and practice tools described here are developing alongside the Innovation Lab, because accessibility is strongest when learning and building grow together.

Learn. Practice. Build. Share.

The Academy is more than a collection of courses. It is a living learning environment where education, experimentation, and collaboration come together to prepare the next generation of accessibility professionals.

Many of the learning experiences within the Academy are supported by tools and prototypes developed in the Innovation Lab, creating a continuous cycle of education, experimentation, and improvement.

Purpose of the Academy

The Academy exists to make accessibility education more understandable, more practical, and more connected to real user experience.

Accessibility is not only a set of standards. It is the difference between someone being able to complete a task independently or needing unnecessary help.

The Academy will focus on teaching accessibility in a way that connects guidelines, assistive technology behavior, usability, and human impact.

Screen Reader First Learning

The Academy follows the same Screen Reader First philosophy as the Open Door Design website.

Learning materials should not require sight to understand the lesson. Navigation should be clear. Headings should be meaningful. Examples should work with a keyboard. Practice activities should provide useful feedback.

If a lesson can be understood and completed efficiently by a screen reader user, it will usually be clearer for everyone else too.

Learning Programs

CPACC Learning Program

A comprehensive learning experience combining guided instruction, interactive lessons, Flash Trainer review, challenge modes, practice questions, and screen reader-first workflows designed to prepare learners for both the CPACC examination and a career in accessibility.

Status: Active development

WCAG Learning Program

A structured learning experience combining plain-language instruction, Flash Trainer review, practical exercises, real accessibility findings, usability discussions, and remediation techniques to help learners understand how WCAG affects real people using real technology.

Status: Active development

Screen Reader User Testing Program

A hands-on learning path focused on headings, landmarks, forms, focus management, links, dynamic content, keyboard interaction, and communicating usability findings from the perspective of assistive technology users.

Status: Curriculum planning

Document Accessibility Program

A practical program covering document structure, tagged PDFs, alternate text, forms, tables, reading order, remediation techniques, and quality assurance using assistive technology.

Status: Curriculum planning

Accessible Media Program

An exploration of captions, transcripts, audio description, accessible video production, narration workflows, and multimedia accessibility from a Screen Reader First perspective.

Status: Research and development

Accessibility Engineering Program

A future learning program for developers and technical professionals who want to build accessibility into products from the beginning through inclusive architecture, semantic structure, keyboard interaction, and assistive technology compatibility.

Status: Future initiative

Practice, Not Just Reading

The Academy will include practice systems, quizzes, challenge workflows, examples, and review activities that help learners apply accessibility concepts instead of only memorizing them.

That includes recognizing barriers, explaining impact, choosing appropriate WCAG success criteria, testing with assistive technology, and documenting issues clearly.

Learning accessibility should feel connected to real work and real people.

Connected to the Innovation Lab

The Academy and the Innovation Lab are separate parts of Open Door Design, but they are designed to support each other.

The Academy teaches the concepts. The Innovation Lab builds tools and prototypes that demonstrate those concepts in action.

Every tool can become a lesson. Every lesson can inspire a better tool.

Explore the Open Door Innovation Lab

Who the Academy Is For

  • People new to accessibility.
  • CPACC candidates.
  • Screen reader users interested in accessibility testing.
  • Developers and designers learning inclusive design.
  • Students and apprentices building accessibility skills.
  • Organizations seeking clearer accessibility education.
  • Anyone who believes accessibility should create independence and opportunity.

Founding Season

The Academy is still taking shape.

Some learning programs are only concepts. Some practice systems are prototypes. Some lessons will change as better examples and community feedback emerge.

That is part of the process.

Open Door Design is not presenting a finished school. It is inviting people to help build one that reflects real accessibility experience.
